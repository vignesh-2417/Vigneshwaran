# First $100 Journal — production pack

Faceless money-making reel series. Copy voiceovers, on-screen text, and captions into CapCut / ElevenLabs.

## Brand (do not change all week)

| Rule | Value |
|---|---|
| Name | First $100 Journal |
| Hook | One confession on the first frame |
| Look | Dark background, huge white text, yellow for money numbers |
| Voice | Calm, slightly fast, not a movie-trailer AI voice |
| Length | 25–35 seconds |
| Ratio | 9:16, 1080×1920 |
| CTA | Follow for the next episode |
| Music | Quiet under the voice, or none. Voice is the product. |
| Visuals | Desk, laptop, phone, notes. No luxury cars, mansions, or “sigma” clips. |

## How to film all 7 in one sitting

1. Record all 7 voiceovers back to back (~12 minutes), or paste each script into ElevenLabs.
2. Duplicate the Day 1 CapCut project 6 times.
3. Swap text + audio only. Same font, same music level.
4. Cut any pause over 0.4s.
5. Post Day 1 today, then one per day.
6. Pin Day 7 on Instagram once it is live.

## Files

| File | Use |
|---|---|
| `day-01.md` … `day-07.md` | Full card: hook, voiceover, timings, caption |
| `voiceovers-only.txt` | Paste into ElevenLabs, one block at a time |
| `captions-only.txt` | Paste into TikTok / Reels / Shorts |
| `on-screen-timings.csv` | Import or keep open while adding text layers |
